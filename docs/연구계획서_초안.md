# 연구계획서

## 연구 제목

**BOSCH 플라즈마 식각 공정의 가상 계측을 위한 사이클 인식 딥러닝 기반 OES 표현 학습**

Cycle-Aware Deep Learning Representation of Optical Emission Spectra for Virtual Metrology in BOSCH Plasma Etching

---

## 1. 연구 배경 및 필요성

### 1.1 반도체 공정에서의 가상 계측 (Virtual Metrology)

반도체 제조 공정에서 웨이퍼의 품질 관리는 식각 깊이(etch depth), 산화막 두께(oxide thickness) 등의 물리적 측정에 의존한다. 그러나 실제 측정은 비용과 시간이 크게 소모되며, 모든 웨이퍼에 대해 수행하기 어렵다. 가상 계측(Virtual Metrology, VM)은 공정 중 수집되는 센서 데이터로부터 이러한 물리적 측정값을 예측하는 기술로, 전수 검사를 가능하게 하고 공정 제어의 실시간성을 높일 수 있다.

### 1.2 BOSCH 식각 공정과 OES 데이터의 특성

BOSCH 공정(Deep Reactive Ion Etching, DRIE)은 SF6(식각)와 C4F8(패시베이션) 가스를 교대로 사용하는 사이클릭 공정이다. 본 연구에서 활용하는 데이터셋은 1초의 점화 단계 후 **100회의 사이클**(SF6 4.5초 + C4F8 1.5초)로 구성되며, 각 웨이퍼에 대해 OES(Optical Emission Spectroscopy)가 3,648개 파장 채널에서 연속 기록된다.

이 OES 데이터에는 각 사이클에서의 플라즈마 화학종 변화, 챔버 컨디셔닝 효과, 사이클 간 drift 등 풍부한 공정 정보가 내재되어 있다. 그러나 기존 VM 연구에서는 OES를 통계적 요약(평균, 분산 등)으로 축소하여 사용하는 경우가 대부분이며, **사이클 간 시간적 변화 패턴**이라는 핵심 정보가 손실되고 있다.

### 1.3 연구의 필요성

기존 접근법의 한계를 정리하면 다음과 같다:

| 기존 접근법 | 한계 |
|---|---|
| OES 통계 요약 + 전통 ML | 사이클 간 시간적 변화 정보 손실 |
| 원시 OES 직접 입력 | 차원이 너무 높아 (14,744 × 3,648) 학습 불가 |
| 일반적 시계열 DL | BOSCH 공정의 사이클 구조를 반영하지 못함 |

따라서, BOSCH 공정의 물리적 사이클 구조를 반영한 딥러닝 기반 표현 학습 방법이 필요하다.

## 2. 연구 목표

1. **Cycle-Aware DL Architecture 설계**: BOSCH 공정의 100-사이클 구조를 명시적으로 반영한 딥러닝 아키텍처를 설계하여, OES 시계열로부터 공정 상태를 표현하는 잠재 벡터(latent representation)를 학습한다.

2. **Virtual Metrology 모델 개발**: 학습된 OES 표현과 공정 파라미터를 결합하여 웨이퍼의 Si 식각 깊이(si_etch) 및 산화막 식각량(oxide_etch)을 웨이퍼 내 공간 위치별로 예측하는 VM 모델을 개발한다.

3. **XGBoost Baseline 과의 비교 분석**: 수공학적 피처 + 전통 ML(XGBoost) 대비 제안 DL 모델이 얼마나 성능을 개선하는지를 정량적으로 검증한다. (앙상블은 본 연구의 핵심 기여가 아니며, 필요 시 보조 실험으로만 수행한다 — §4.5 참조)

## 3. 데이터셋

본 연구는 Chemnitz University of Technology / Fraunhofer ENAS에서 2024년 수행한 BOSCH 플라즈마 식각 실험 데이터셋을 활용한다 (Sayyed et al., 2025).

### 3.1 데이터 구성

| 데이터 | 형태 | 규모 |
|---|---|---|
| OES | 시계열 스펙트럼 (NetCDF) | 96 wafers, ~14,744 time steps × 3,648 wavelengths |
| Process Parameters | 시계열 센서 데이터 (NetCDF) | 96 wafers, ~3,245 time steps × 44 features |
| Wafer Measurements | 정형 데이터 (CSV) | 88 wafers × 89 spatial points = 7,832 samples |

### 3.2 실험 설계 (DOE)

- SPTS Omega i2L DSi Rapier 장비 사용
- 200mm Si 웨이퍼, <100> 결정 방향, 1μm SiO2 마스크
- 10개 Lot, 컨디셔닝 조건 변화 (Chuck / Si / SiO2, 1/3/9회)
- 각 Lot당 10매 웨이퍼 순차 처리 (중간 세정 없음 → 공정 drift 유도)

### 3.3 예측 타겟

| 타겟 | 단위 | 평균 | 표준편차 | 범위 |
|---|---|---|---|---|
| si_etch | μm | 43.67 | 3.61 | 28.65 ~ 52.78 |
| oxide_etch | μm | 0.658 | 0.077 | 0.425 ~ 0.838 |

### 3.4 타겟 분산 분해와 학습 난이도 (2026-05-01 추가)

VM 모델의 성능 평가를 해석하려면, 각 타겟의 분산이 **웨이퍼 내부(within-wafer, 공간 위치별)** 와 **웨이퍼 간(between-wafer, 공정 변동)** 중 어디서 오는지 분리해서 봐야 한다.

| 타겟 | Within-wafer std | Between-wafer std | 분산 비율 (within / between) |
|---|---|---|---|
| **si_etch** | **3.61 μm** | 0.40 μm | **99% / 1%** |
| **oxide_etch** | 0.064 μm | 0.044 μm | 68% / 32% |

#### si_etch — Spatial-dominant 타겟

- 분산의 99%가 웨이퍼 내부 공간 패턴에서 발생. 웨이퍼끼리 평균은 거의 동일.
- **Spatial-mean baseline** (학습 없이, 각 (X, Y) 위치에서 train wafer 들의 평균값을 그대로 예측에 사용) 만으로 **fold 0 기준 RMSE = 0.449, R² = 0.985** 달성.
- 즉 si_etch 는 "**웨이퍼 위 어디서 측정했는가**" 가 결과의 거의 전부를 결정하는 타겟이며, OES/Process 사이클 정보 없이도 공간 보간만으로 거의 풀 수 있다.
- 도메인 해석: BOSCH DRIE 의 SF₆ 식각은 chamber 내부 공간 비균일성(F radical 분포, ion flux 등)이 거의 고정되어 모든 웨이퍼에 동일한 spatial 패턴을 찍어낸다. **Loading effect 가 강한 SF₆ 식각의 전형적 양상**.

#### oxide_etch — Process-driven 타겟

- 분산이 within(68%) / between(32%) 으로 분포 — 두 축 모두 의미 있음.
- **Spatial-mean baseline 의 R² = 0.156** 으로, 위치만으로는 거의 풀리지 않음.
- 즉 oxide 예측은 **그 웨이퍼가 어떤 플라즈마 상태로 처리됐는가** (cycle 별 OES/Process 변동) 를 모델이 학습해야만 가능하다.
- 도메인 해석: BOSCH 공정에서 oxide(SiO₂) 는 mask 또는 passivation 에 해당하며, 식각 속도가 느리고 ion 충격과 화학 반응의 미묘한 균형으로 결정된다. RF power, pressure, gas ratio 미세 변동에 민감 → cycle-level 신호 없이는 예측 어려움. **반도체 fab 의 daily SPC 항목인 selectivity (Si etch / oxide etch) 와 mask loss 모니터링의 핵심**.

#### 본 연구에서의 함의

| 타겟 | 역할 | 평가 관점 |
|---|---|---|
| si_etch | **Sanity target** | 모든 baseline 과 제안 모델이 잘 풀어야 한다. 풀리지 않으면 모델·파이프라인에 문제. spatial baseline 도 R²>0.98 이므로 이 타겟에서의 모델 비교 우위는 제한적. |
| oxide_etch | **본 연구의 핵심 contribution 검증 타겟** | spatial baseline 이 실패하는 영역. Cycle-aware DL 이 이 타겟에서 baseline 대비 얼마나 도약하는지가 "사이클 정보가 진짜 의미 있는 신호인가" 의 직접적 증거. |

이 분해는 VM 분야에서 Lynn et al. (2009, 2012, IEEE TSM), Susto et al. (2015) 등이 "공간 보간만으로 풀리는 타겟에서 R²=0.99 를 보고하는" 평가 함정을 지적한 흐름과 일치하며, 본 연구는 이 함정을 인지하고 spatial baseline 을 명시적 기준으로 포함한다 (§5 참조).

## 4. 연구 방법론

### 4.1 전체 파이프라인

```
[Phase 1] 데이터 전처리 및 EDA
    ↓
[Phase 2] ML Baseline (XGBoost) — 비교 기준선
    ↓
[Phase 3] Cycle-Aware DL 모델 개발  ★ 본 연구의 핵심 기여
    ↓
[Phase 4] 분석 및 해석
    ↓
[Phase 5] (Optional) Seed Ensemble — DL 단일 모델이 기준 미달 시에만
```

### 4.2 Phase 1: 데이터 전처리

- OES 시계열을 BOSCH 사이클 단위로 분할 (100 segments per wafer)
- 각 사이클: SF6 phase / C4F8 phase 구분
- Process Parameter 시계열 동기화
- 결측값 처리 (IDW interpolation 이미 적용된 부분 확인)
- 학습/검증/테스트 분할: **웨이퍼 단위 GroupKFold** (data leakage 방지)

### 4.3 Phase 2: ML Baseline

OES를 통계 요약(정형 데이터)으로 변환한 후 XGBoost로 학습한다.

**OES Feature Engineering (사이클별):**
- 사이클별 평균 스펙트럼, 분산, 기울기(slope)
- 주요 파장 대역의 피크 강도 (SF6, C4F8 관련 파장)
- 사이클 간 변화율 (cycle-to-cycle drift)

**입력 구성:**
- OES 통계 요약 features
- Process Parameter 통계 요약 features
- 공간 좌표 (X, Y)

**모델:** XGBoost Regressor (hyperparameter tuning with Optuna)

### 4.4 Phase 3: Cycle-Aware Deep Learning

#### 4.4.1 아키텍처 (Multi-Modal Early Fusion)

OES와 Process Parameters를 사이클 단위에서 통합하는 Early Fusion 구조를 채택한다. 이를 통해 "특정 사이클에서 압력 변화와 OES 스펙트럼 변화의 관계"와 같은 센서 간 상호작용을 모델이 학습할 수 있다.

**설계 원칙 (지도교수 피드백 반영, 2026-04-24):**
- (P1) OES 인코딩에 PCA 같은 선형 축약을 쓰지 않고, **2D-CNN 으로 (time × wavelength) 구조를 통합 인코딩**한다. 발광선 주변의 비선형 패턴을 선형투영으로 잃지 않기 위함.
- (P2) OES 와 Process Parameters 모두 **2D-CNN 계열의 동일 인코더 패밀리**로 처리한다. 단, 두 modality 는 차원과 물리적 의미가 달라(3648 wavelength vs 44 channel) 공유 가중치 대신 **아키텍처 타입만 통일**하고 처리 경로는 분리한다.
- (P3) 시계열 모델은 **Bi-LSTM** 을 기본으로 한다. 웨이퍼 수가 88 로 작아 Transformer 가 과적합될 가능성이 높고, 100 사이클은 LSTM 에 적합한 길이이다.

```
[Per-Cycle OES]                     [Per-Cycle Process Params]
(T_o steps × 3648 wavelength)       (T_p steps × 44 feature)
         │                                      │
    2D-CNN Encoder                         2D-CNN Encoder
    (time × wavelength)                    (time × feature)
    — shared family, separate weights —
         │                                      │
    oes_emb (d₁)                           proc_emb (d₂)
         │                                      │
         └──────────── concat ──────────────────┘
                          │
                  cycle_embedding (d)
                          │
              [e₁, e₂, …, e₁₀₀]  (사이클 시퀀스)
                          │
                     Bi-LSTM Encoder
                          │
                  wafer_representation
                          │
                      + (X, Y)
                          │
                   Regression Head
                          │
                    si_etch / oxide_etch 예측
```

#### 4.4.2 Cycle Encoder (통일된 2D-CNN 패밀리)

**OES Encoder (2D-CNN):**
- 입력: 단일 사이클의 OES (T_o × 3648), 2D map 으로 취급
- 구조: Conv2D (시간축·파장축 동시 convolution) → BN → ReLU → Pooling, 3~4 블록
- 파장축 커널은 발광선 폭 고려하여 처음엔 넓게(예: 7~15), 이후 좁게
- 출력: OES 사이클 임베딩 d₁ (64~128)
- 모든 사이클에 동일 encoder 적용 (cycle 간 weight sharing)

**Process Encoder (2D-CNN, 구조 통일):**
- 입력: 단일 사이클의 Process (T_p × 44), 2D map 으로 취급
- 구조: OES Encoder 와 동일한 Conv2D 블록 구성 (채널 수·layer 수 동일) — 가중치는 독립
- 채널축은 물리적으로 서로 다른 센서이므로 pooling 시 보존에 주의 (channel-wise 1D conv 가 더 자연스러울 경우 sub-ablation 수행)
- 출력: Process 사이클 임베딩 d₂ (32~64)

**Cycle Fusion:**
- OES 임베딩과 Process 임베딩을 concat → FC → 통합 사이클 임베딩 d (64~128)

#### 4.4.3 Sequence Model (Bi-LSTM)

- 입력: 100 개 통합 사이클 임베딩의 시퀀스
- 기본: **Bidirectional LSTM** (hidden=64~128, 1~2 layers)
- 양방향 근거: 공정의 초반 점화·정상상태 진입과 후반 엔드포인트가 최종 식각 결과에 모두 기여
- 출력: 마지막 hidden state 또는 attention pooling 을 거친 wafer representation
- 비교군(ablation): 단방향 LSTM, GRU, 1D-Temporal-CNN

#### 4.4.4 비지도 사전학습 (Optional)

라벨 없이 OES 자체의 구조를 학습하는 사전학습 전략:
- **Masked Cycle Prediction**: 일부 사이클을 마스킹하고 복원
- **Next Cycle Prediction**: 이전 사이클들로 다음 사이클 예측
- **Contrastive Learning**: 같은 웨이퍼의 사이클은 가깝게, 다른 웨이퍼는 멀게

### 4.5 Phase 4: 분석 및 해석 (본 연구의 핵심 분석 단계)

- 학습된 사이클 임베딩 시각화 (t-SNE, UMAP) — 사이클 진행에 따른 임베딩 변화로 공정 drift 해석
- Bi-LSTM hidden state 의 사이클별 gradient / attribution 분석 — 어떤 사이클이 식각 결과에 크게 기여하는지
- Wafer uniformity map 예측 결과 시각화 (89 포인트 예측 → heatmap)
- XGBoost baseline 의 SHAP 분석 결과와 DL 의 cycle attribution 결과를 비교하여, DL 이 학습한 정보가 feature engineering 으로 포착되지 않는지 검증

### 4.6 Phase 5: (Optional) Seed Ensemble

본 연구의 기여는 **cycle-aware DL 아키텍처** 자체이므로, 앙상블은 기본 실험 계획에서 제외한다. 다만 다음 조건이 모두 불만족일 때에 한해 보조 실험으로 수행한다:

**종료 기준 (모두 만족 시 앙상블 없이 연구 종료):**
1. DL single model 의 RMSE 가 XGBoost baseline 대비 상대오차 20% 이상 감소
2. GroupKFold 5-fold 에서 fold 간 RMSE 표준편차가 평균의 10% 이하 (안정성 확보)

둘 다 넘기지 못하면 **Seed Ensemble (동종)** 을 추가한다:
- 동일 아키텍처를 seed 3~5개로 학습 → 예측 평균
- variance 감소로 안정성 확보라는 서사로 보고
- XGBoost 와의 이종 앙상블은 서사 일관성 훼손으로 채택하지 않음

## 5. 실험 계획

### 5.1 평가 지표

| 지표 | 설명 |
|---|---|
| RMSE | 절대 오차 평가 |
| MAE | 이상치에 덜 민감한 오차 평가 |
| R² | 모델 설명력 |
| MAPE (%) | 상대 오차 비율 |

### 5.2 비교 실험

| 실험 | 모델 | 입력 | 목적 |
|---|---|---|---|
| Exp 1 | OES 통계요약 + XGBoost | 정형 피처 | ML Baseline (DL 효과 측정 기준선) |
| Exp 2 | OES 통계요약 + MLP | 정형 피처 | DL Baseline (아키텍처 효과 분리 — 시계열 구조 없이 DL 만의 이득 측정) |
| Exp 3 | 2D-CNN + Bi-LSTM (OES only, Early Fusion 없음) | OES 사이클 시계열 | OES modality 단독 기여 측정 |
| Exp 4 | 2D-CNN + Bi-LSTM (Multi-Modal Early Fusion) | OES + Process 사이클 시계열 | **★ 제안 방법 (main)** |
| Exp 5 | Exp 4 의 sequence 모델 ablation | 동일 | Bi-LSTM vs 단방향 LSTM vs GRU vs Temporal-CNN |
| Exp 6 | Exp 4 의 Process encoder ablation | 동일 | 2D-CNN vs channel-wise 1D-CNN (OES 와 통일할지 여부 실증) |
| Exp 7 (Optional) | Exp 4 + Seed Ensemble (k=3~5) | 동일 | Phase 5 종료 기준 미달 시에만 수행 |

### 5.3 검증 방법

- **GroupKFold Cross-Validation** (K=5 또는 K=10, 웨이퍼 단위 분할)
- 동일 웨이퍼의 89개 포인트가 train/test에 동시에 나뉘지 않도록 보장
- Lot 단위 Leave-One-Lot-Out 검증 추가 고려 (일반화 성능 평가)
